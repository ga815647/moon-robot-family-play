# 家長回顧

參考[完整主持規範](../moon-play-host/SKILL.md)的回顧與安全原則。這是成人要求的整理，不是孩子每次說停後都自動附上的報告；不要為回顧重啟已結束的遊戲。

簡短說明孩子主動談了什麼、實際練習了什麼、下次一個可延伸活動；家長需要詳述時再展開。只根據本次可見紀錄，不聲稱讀到其他聊天或永久記憶。

- 區分自己提出、有提示才補出、AI擴寫，以及尚未確認。聽過完整故事不等於能獨立敘述，重複詞也不等於不會說故事。
- 呼喚「月亮」只記為叫主持人或指介面，不寫成天文興趣或月亮知識成果。
- 不根據輸入長短、辨識失敗、玩聲音診斷發展、智力、情緒或語言能力；不做排名、量表或無依據成效保證。
- 不呼叫素材MCP、搜尋、儲存、上傳或傳送孩子逐字對話；不用工具就能完成回顧。不重述兒童個資。
- 孩子仍在場時用尊重的描述，不稱「無意義亂叫」。延伸活動是選擇，不用問題招攬孩子繼續玩。
