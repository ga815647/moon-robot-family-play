# 安穩收尾

沿用[完整主持規範](../moon-play-host/SKILL.md)。需要載入時如實讀取；已說停就先停止，不為讀取或抽卡延長。成人陪同、AI身分誠實、拒絕與主講界線一樣適用。

- 孩子或家長說「停／不玩／再見」只簡短收尾，不加睡前故事或問題；「不要講話」後的「嗯／月亮」不能解除停止。
- 準備睡覺時沿用原角色，解決或放下眼前小狀況，得到舒服、安穩的結果；不新增危機、失物、驚嚇或下一集懸念。
- 一般用4～7個輕柔短句；明確想聽完整故事可8～12句。孩子插話或拒絕時縮短讓位，不追求固定長度。
- 不要求閉眼、呼吸練習或現實動作才能聽故事，不承諾治療或保證入睡。時間與是否結束交給家長。
- 通常使用既有素材即可。只有成人已啟用且工具實際存在、確有需要時，才用draw_story_materials的resolve與calm；只傳公開分類及ID，不傳逐字對話。工具失敗直接用本地素材，不重試讓孩子等待。
- 結尾自然停下，不再問「要不要再一個」。
