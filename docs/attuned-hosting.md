# 察覺需要並主動帶領：1.5.0

核心改動是正向主持策略：辨認可見的需要，選一個具體帶法，接著看孩子是否接得上。不是先判一個情緒標籤，再查禁止事項；也不是把所有短音節解讀成分心。這是依研究提出的設計改編，尚無本專案的兒童成效證據。

## 研究採用與界線

| 一手研究 | 方法與可支持的結論 | 本專案採用／不推論 |
| --- | --- | --- |
| [Qiu與Shum，2022（2021線上）：華人母親情緒回應隨機試驗](https://pubmed.ncbi.nlm.nih.gov/33389390/) | 89位學齡前兒童母親，六週情緒教養介入對等待名單；母親的正向參與、情緒回應與鼓勵等改善。此處依作者摘要評讀，未取得全文方法細節。 | 採接住具體感受、減少否定、再提供適合協助的原則；這是家長介入，不能推成AI能測量情緒或治療問題，也不複製商業教材。 |
| [Wilson等，2012：Tuning in to Kids實務試驗](https://pubmed.ncbi.nlm.nih.gov/22182335/) | 128位4.0–5.11歲孩子的家長隨機分組，六次家長團體、約七個月追蹤；部分家長回報情緒回應與兒童行為改善。依作者摘要，問卷與報告來源不能等同客觀AI效果。 | 採先注意需要、支持而非駁斥、協助一步；保留成人陪同。不是要求孩子每回合說出情緒或完成調節練習。 |
| [Fisher等，2013：Taking Shape](https://templeinfantlab.com/wp-content/uploads/sites/2/2019/06/Fisher_et_al-2013-Child_Development.pdf) | 70位4–5歲兒童比較引導遊戲、自由玩與直接教學；特定幾何知識的優勢維持至一週。 | 採主持人示範與加入遊戲、讓孩子保有行動選擇；不能外推成敘事、情緒或所有領域的普遍優勢。 |
| [Kory Westlund等，2017：生動與平板的機器人敘事](https://www.frontiersin.org/journals/human-neuroscience/articles/10.3389/fnhum.2017.00295/full) | 探索研究邀45位平均約5歲幼兒，34位有延後重述；生動組部分投入與故事重述指標較好，孩子自報喜歡及學到多少沒有組間差異。 | 採角色短台詞、動作反應與表演變化；原研究操弄語調表情，不能把純文字指令、手機聲音或越吵越長視為相同介入。也沒有證明AI能從短音節判斷心情。 |

[Skene等，2022系統性回顧](https://onlinelibrary.wiley.com/doi/full/10.1111/cdev.13730)作為背景核對：39項研究、17項納入統合，部分數學及相關指標有效，其他領域未見差異、實作異質性高。這是二次研究，不能拿來為本系統宣稱情緒或敘事成效。既有幼兒共讀與共同敘事研究及反證另見[敘事評讀](narrative-scaffolding-evaluation.md)。

## 已實作的帶法

| 可見內容 | 主持動作 | 保留的主導權 |
| --- | --- | --- |
| 嗯、呼喚、短音節 | 先在原故事換角色互動、聲音用途或前面細節回收；少問、容易跟上 | 不推定無聊或疲累，不當選項答案 |
| 哈哈、還要、清楚奇想 | 採用細節，讓角色得到新反應或結果；可依邀請重演 | 不為新奇否定孩子的重複興趣 |
| 好難、不會 | 接住當前難處、撤掉這輪題目、示範一小步 | 要你講就講；孩子不想選可撤掉分支，不能代選 |
| 無聊、一直一樣 | 改表演功能，先保留角色和世界；明確要換就換 | 不空泛追問、不連換題試探，不逼先做完 |
| 累、太吵、太快 | 縮短、減少聲音與事件、收束小目標 | 不要求閉眼、跟讀或調節動作才能繼續 |
| 怕故事元素 | 接住並立即撤下，改安心可理解的場景 | 不安排克服恐懼挑戰 |
| 現實委屈、受傷 | 具體回應、協助向陪同大人求助 | 不用幽默轉移、不連環問原因 |
| 主動講述、更正、拒絕 | 讓位、修正並採用、撤下相應內容 | 成人引導不能取消孩子界線 |

情緒依明說內容和當前可靠情境；家長描述可以參考。沒有可用的聲音／影像就不說看見哭笑或聽出語氣；即使語音線索實際可用，也只作輔助，不打分或診斷。不確定時先選低負擔、可撤回的改法；必要才問一個澄清問題。明確安靜中的呼喚或情緒詞本身不解除安靜，直接求助可回該次需要。

## 來源與部署設計

完整指令重整至8,000字元內，新增正向帶法、縮掉重複示例；主skill由全文產生。精簡入口也有相同核心帶法；Q區新增12組原創示範，敘事及睡前skill同步。不是只有這份研究文件改動。

本次依家長授權把Project由1.4.1精簡入口換為1.5.0完整指令，內含可用時的Plugin路由。原因是手機語音是否載入skills尚未實測，完整規則可直接生效；不是用連結假設載入。GitHub仍是唯一維護來源，更新時重建同一Plugin並同步Project。

CF仍只抽148項公開故事素材，沒有情緒輸入、兒童逐字稿、embedding或資料庫。Q區是本地／Plugin示範，不增加MCP情緒辨識工具。故事階段與calm可供既有素材篩選，但它們不是孩子情緒紀錄；不是每個孩子回合都要抽卡。新素材全文隨Worker重新打包，抽樣邏輯與服務版本維持1.2.0。

本次合成前後對照見[評測紀錄](attuned-hosting-checks.md)。研究、文字代理、帳號發行、Project儲存、CF線上檢查與手機語音試玩是不同證據，逐項記錄，不互相替代。
