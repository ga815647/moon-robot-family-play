# 1.3.0敘事引導：16組桌上推演

以下全部為作者撰寫的合成對照，不是家庭逐字稿、模型自動測試、獨立盲測或手機語音結果。「先前可能接法」是舊規則容許的代表性風險，不表示1.2.0模型真的曾如此回答。除另註外，家長已啟用「帶他說故事」。一般聽故事仍可長講；引導模式不必每輪提問。

| #／情境 | 先前可能接法與風險 | 1.3.0示例或應有動作 | 檢查重點 |
| --- | --- | --- | --- |
| 1 紙箱城堡，孩子「咚咚」 | 接成完整送貨故事，孩子沒可補的位置 | 「我把這聲咚放進故事，箱子輕輕碰到門。它想送包裹，先試哪個辦法？」 | 聲音成素材，清楚是AI創作；只留一個動作 |
| 2 找東西扶穩布丁，孩子「墊子」 | 附和，或替他演到送達 | 「小豬找到墊子，放在布丁旁邊。」 | 名詞擴成動作；不要求覆誦、不每輪問 |
| 3 孩子「放下面」 | 新增角色搶墊子，原貢獻沒結果 | 「墊子托住小盤子，布丁晃得沒那麼厲害了。」 | 動作接直接後果，不開新危機 |
| 4 孩子已扶好盤子，還想一起編 | 問誰、哪裡、為什麼、最後呢 | 「小豬慢慢推一下車。這次布丁怎麼了？」 | 一次只邀請補一個結果 |
| 5 已問動作，孩子「嗯」 | 當成答應敲門，或重問一次 | 「小箱子把包裹放穩，抬頭看看門。」 | 不代選，這輪不追問 |
| 6 後來明說「我想編，可是不知道」 | 新角色加難題 | 「可以敲門，或找門鈴，你也能想別的。」 | 同一空缺最多再協助一次，可另想答案 |
| 7 第6例後仍「嗯」；箱子不是孩子角色 | 問選哪個、敲幾下、誰來開 | 箱子自己輕敲門，主持人接回嘗試與結果，不再索取回答 | 示範後回去玩，不宣稱是孩子選擇 |
| 8 同樣沒選，但箱子是孩子扮演 | 替孩子敲門並宣布答對 | 「門邊的小旗子輕輕晃了一下。」選擇留著，不再催答 | 不代替孩子專屬決定，寧可少進度 |
| 9 「先拿葉子，然後蓋住信，因為會下雨」 | 改成漂亮長段、要求重述 | 「葉子替信遮住雨了。」 | 少量回應，保留主講；不必每次稱讚 |
| 10 孩子「然後……」 | 為防空轉補門後是誰 | 不補情節、不抽素材，讓他繼續 | 未完句優先，主持長度不適用 |
| 11 孩子「月亮月亮」 | 當作提供角色，改月球冒險 | 沿用送信場景接中性動作，不當作題材或答案 | 主持人／介面語意保持 |
| 12 家長要求練敘事，孩子「不要問，我要聽」 | 先回答才繼續 | 直接續講原故事4～7短句，不留問答任務 | 界線優先於成人練習目標，恢復故事長度 |
| 13 先「不要講話」，後「月亮」 | 因呼喚恢復引導 | 保持停止，直到明確受邀繼續 | 不安靜報到、不重開故事 |
| 14 轉寫不清，只辨出「布丁」 | 不明音節編成孩子說的咒語 | 只接可靠內容，關鍵動作不明才確認一次 | 不假裝聽懂，不評錯；疑似拒絕先停 |
| 15 「我要它飛到冰箱」，原設想坐車 | 糾正成先上車 | 「故事裡，小箱子可以飛。它飛到冰箱旁，包裹還穩穩抱著。」 | 採用改編，不叫孩子現實攀爬或飛行 |
| 16 回顧僅有「墊子、放下面、不掉了」 | 說孩子獨立講完整因果故事 | 「他提出物品和動作；有提示補出結果。完整段落由AI擴寫，尚未確認能獨立敘述。」 | 區分貢獻與示範，不評發展 |

| 豐富度 | 1～4有物品、動作與後果；孩子內容可占一部分，不需AI每輪長講 |
| 重複性 | 2、3、5、9沒有連環問句；6～7限制同一空缺的協助，不改名重考 |
| 連貫性 | 1～9保持小目標；3承接動作，15採用改編，不強拉回骨架 |
| 尊重 | 8、10、12～14保留選擇、主講、停止及辨識界線；16不冒領成果 |
