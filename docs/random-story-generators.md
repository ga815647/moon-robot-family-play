# 隨機故事產生器的可用機制

除了SillyTavern等角色扮演工具，獨立故事產生器更直接呈現「哪些欄位能組合成故事」。本次於2026年10月18日補充研究以下一手來源；前一版素材庫為自行創作，當時沒有宣稱已採用這些產生器的實作。

後續1.2.0已把角色需求與關係、骨架、欄位綁定及暫用素材袋寫入[完整指令](../PROJECT_INSTRUCTIONS.md)及[148項素材庫](../STORY_MATERIALS.txt)，並部署[Worker抽素材工具](worker.md)。以下保留研究依據，實際整合例子見[生成器整合案例](generator-integration-checks.md)。

## 已查到的機制

| 來源 | 可從一手資料確認的機制 | 對月亮機器人的用途 |
| --- | --- | --- |
| [Aardgo Plot Generator的Story Generator](https://www.plot-generator.org.uk/story/) | 表單分開提供開場、衝突、解決方式、主角、次要角色、次要角色想向主角取得什麼、地點與物件等欄位，也提供隨機填入入口 | 候選不只抽名詞，也要抽一個角色需求或關係，讓角色有互動原因 |
| [Aardgo Twist Generator](https://www.plot-generator.org.uk/twist/) | 可設定主角、其他角色及彼此關係，選擇產生的提示數量 | 轉折應接上已知角色關係，而非每次換新世界；轉折不必每回合使用 |
| [Tracery的原作者repo](https://github.com/galaxykate/tracery) | 用可展開規則組合文字；示例把主角名字與寵物選定後綁定，再在同一故事中重用 | 鎖定人物與重要物件，再改變動作、意外或結果，減少故事中途換人 |
| [Rory’s Story Cubes官方介紹](https://www.asmodee.ca/en/product/rorys-story-cubes-mystery/) | 擲出圖像後，把物品、角色、地點或動物串成故事；原玩法使用九個朝上圖像 | 借用跨類元素連結，不要求5歲孩子一次處理九項；由主持人把少量素材演成可聽的故事 |
| [Corpora原作者repo](https://github.com/dariusk/corpora) | 以小型JSON語料分類儲存可供文字生成使用的資料；它是素材集，不是故事引擎 | 素材可獨立維護並依類別組合；但適齡、台灣口語及故事因果仍需另行設計 |

Plot Generator的欄位已實際讀取，但未檢查其內部產生程式，不能只因畫面有隨機按鈕就斷言其演算法。Tracery的規則與變數綁定依原作者README確認；未安裝或執行該套件。Story Cubes只借組合玩法，沒有搬用商品圖案或推薦必須購買。

[Perchance](https://perchance.org/tutorial)也列入候選；本次工具讀到教學入口，但正文位於動態iframe，未取得可核對的完整教學內容，因此不把其特定加權或不重複功能列為已驗證、已採用。

## 改進抽素材的方法

以下是本專案的設計判斷，並非上述網站的原文規則。

選材分成兩層：先留住當前的角色、場景、小目標和未定選擇；再從約10個候選中，選2～3個互補的事件或表演元素。比起每次抽「小豬＋城堡＋布丁」，可以改抽「很認真地招待客人＋把物品當客人＋換一個擺法就解決」。

可用的小故事骨架是：
角色想完成一件事 → 某個具體小狀況讓方法不順 → 角色作出反應或嘗試 → 已有物件或細節幫上忙 → 得到小結果。
不必每回合走完整套；孩子正在主講、解題或作重要選擇時，把下一步留給他。孩子只是叫「月亮」時，主持人可自行演出一小段。

## 一個原創示例

沿用角色：機器人。沿用場景：點心公車。沿用目標：讓乘客坐好。
挑選元素：過度有禮貌、椅子被當乘客、用途誤會自己解開。

機器人今天負責帶乘客上車。它看見門口寫著「請坐」，便先向一張椅子鞠躬。椅子沒有動，機器人又搬來另一張椅子，想讓它坐下。小豬看看疊起來的椅子，小聲說：「可是我還沒有地方坐。」機器人這才把兩張椅子排回原位，請小豬坐好。出發前，它還是認真向椅子說：「謝謝你借我們坐。」

這段用同一個誤會推進六句，有角色互動與結果，不需要每句都加新角色，也不要求孩子回答才能繼續。

## 與embedding及MCP的關係

這些例子顯示，規則組合與分類素材本身就能提供創意來源；並不必然需要語意向量。這是選擇第一版標籤加抽樣方案的理由，不表示向量檢索永遠沒有用途。

若未來實作MCP，可提供「角色需求、事件、表演方式、回收點」等類型的候選，並接受已知人物及近期ID來篩選；不要僅回傳隨機名詞。若素材量變大或標籤無法處理語意查詢，再評估對故事摘要做embedding。

研究補充當時沒有改動執行內容；後續已在1.2.0完成指令、素材與Worker整合。要使用新版行為，需由家長同步1.2.0完整指令及素材檔；Project遠端設定尚未直接更動。
