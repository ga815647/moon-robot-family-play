# 1.4.1主持空轉檢查

日期：2026-10-18。本次以不同代理產生多輪文字，再由另一代理評讀；不是只由改寫者寫出理想示範，也不是目標手機語音模型測試。

## 觀察與修正範圍

本機可讀到的最新家庭對話片段有明顯重複的收話、安靜與等待宣告，同一回覆還串接多段類似說法。部分重述詞不在對應的可見輸入；語音切片、轉寫及更早歷史不完整，不能直接斷言是幻覺，也無法確認最初是否有人要求安靜。真實紀錄不加入公開repo。

前一次唯讀查看的線上Project仍是最初版本，尚未套用repo完整規範或精簡入口，因此該片段不能當作1.4.0 Plugin的實測失敗。檢查1.4.0文字後，仍找到需補明確的漏洞：只列常見禁語，未涵蓋同義收話行為；未明說AI自己的舊承諾不能建立安靜狀態；中性動作可能反覆而沒有結果；直接提問的單次邀請與停止規則存在解讀空間。

1.4.1已同步修正完整規範、備援、共同敘事／睡前skills及素材示範：

- 一般回合直接回答，或演動作與後果、角色反應或發現。拿掉陪伴狀態句後若沒有內容，就重寫；不換同義詞或讓角色代替AI等孩子。
- 安靜只由人類明確要求建立，AI舊承諾不算；不搶一輪不等於永久靜音，也不匯入別段聊天狀態。
- 真正安靜後不反覆確認或朗讀括號沉默。直接對AI提問只答該題，再回原先安靜／主講狀態；短音節與暱稱不解除。
- 放道具仍可用，但要有用途或後果；不為求進度代替孩子選擇。聲音直接演進原場景，不先報告正在收詞。
- 測試中另外發現載入失敗告知會變成流程旁白；已改為直接用備援，家長問設定或版本時才誠實說明。

## 測試方法

[18組固定合成案例](../eval/hosting-cases.json)涵蓋短輸入、主講、真正停止、直接提問、單句邀請、局部拒絕、睡前、未決選擇，以及多輪舊AI台詞污染。全部是原創內容，不是兒童逐字稿。

兩個不同Codex文字代理分別依1.4.0、1.4.1生成：每案獨立重置，案內沿用自己的回覆。每版完整規範18案47輪，另測只見精簡入口、未載入Plugin的8案23輪；共140個文字回合，包含應無可朗讀內容的回合。

第三個代理依[固定標準](../eval/hosting-rubric.md)評讀；先移除版本標籤，A為1.4.1、B為1.4.0。這不是正式盲測研究：生成代理知道正在測試，也能看見案例期待分類，評讀只有一次質性判斷。備援告知衝突在生成過程修正後，代理重新讀取最終入口並生成備援結果。

## 發行與限制

已更新同一私人Plugin至1.4.1，帳號回讀四個skills、素材及MCP設定與產物相符；身分、受眾、MCP連線與預設提示保留。29項程式檢查及打包通過，148項原子素材完全不變，不需重部署Worker。

已依家長檢查後完成的要求，備份原Project指令並套用1.4.1入口；重新開啟設定確認與正式檔相符，記憶及空間權限保留。尚未在孩子實際手機語音試玩；舊對話仍可能受歷史台詞影響，應在新聊天確認載入版本。測試空字串表示不產生可朗讀內容，不代表已驗證手機能完全無聲；文字規則無法控制語音系統每個行為。
