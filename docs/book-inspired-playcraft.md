## 八種帶法已落入哪裡

| 帶法 | 情境→主持動作 | 原創素材與落點 |
| --- | --- | --- |
| 接住再減負擔 | 明說難、失望→貼近那件事回應，示範或撤掉作答條件 | W01；完整規範及精簡備援 |
| 道具開口 | 已有物品、適合想像→一句短願望，角色以行動接住 | W02；完整主持skill |
| 可愛誤會 | 一次無害小誤會→角色自己察覺，演出結果；也能能幹 | W03；不要求孩子糾錯、不故意錯答知識 |
| 彼此有用 | 兩個角色各有能做的事→互相幫一小步 | W04；旁聽也完整，不指派孩子救援 |
| 邀請換位 | 孩子明確想換→只改明說的角色 | W05；共同敘事skill，不代派孩子角色 |
| 採用奇想 | 清楚設定→動作與直接後果，更正立即採用 | W06；共同敘事skill，不取代孩子版本 |
| 小片段演出 | 孩子講完且受邀→只演已說內容的一個畫面 | W07；共同敘事skill，未完句和接一句仍受尊重 |
| 熟梗換反應 | 指定聲音／重演→保留喜好，換用途、對話或結果 | W08；睡前skill以安穩小結果收束 |

每輪選合適的一種即可，不依序輪播、不宣布教育目標或書名。呼喚月亮和短音節不是情緒、選項或新設定證據。真實委屈先支持，拒絕和主講優先；遊戲中的奇幻與現實能力分開。

## 與1.5.0的差異

既有版已有感受承接、減負擔與讓位。本版主要補表演的可選動作及原創長短示例：角色互助、道具短台詞、作者地位、受邀演出、換位及熟梗變化。重整重複段落，使全文仍在Project的8,000字元內；沒有另外增加必讀摘要、資料庫、付費服務或情緒輸入。

W區不是MCP原子卡，抽樣仍148項、服務邏輯1.2.0。CF重新打包同一素材全文，Plugin直接附W區，Project完整規範則含八種精簡帶法；就算附件或skill未載入也能接戲。手機語音是否載入skills或MCP仍待實測。
